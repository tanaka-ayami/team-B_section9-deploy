## 画面遷移図

```
【未ログイン】
  └─ UI-001 ログイン・サインアップ
        │ 認証完了（BE側で個人グループ自動生成）
        ▼
【ログイン済み】
  │
  ├─ UI-002 カレンダー画面（ボトムナビ：カレンダー）
  │     ├─ 📷 FAB タップ ──────────→ UI-003 書類をスキャン
  │     │                                 │ 撮影 or ライブラリ選択
  │     │                                 ▼ POST /scan
  │     │                           UI-004 解析結果の確認・編集
  │     │                                 │ 登録ボタンタップ
  │     │                                 ▼ POST /documents
  │     │                           UI-002（戻る。他メンバーへ通知発火）
  │     └─ 書類カードタップ ─────→ UI-005 書類の詳細
  │                                       │ 再編集 / 済スタンプ / 削除
  │                                       ▼
  │                                 UI-002（戻る）
  │
  ├─ UI-007 書類一覧画面（ボトムナビ：書類一覧）
  │     └─ 書類カードタップ ─────→ UI-005 書類の詳細
  │
  └─ UI-006 設定画面（ボトムナビ：設定）
        ├─ グループ行タップ ────→ UI-006-G グループ管理
        │                                │ 招待 / 名前変更 / 削除
        │                                ▼
        │                          UI-006（戻る）
        └─ 「新しいグループを作成」タップ → UI-010 新しいグループを作成
                                                 │ 作成ボタンタップ（POST /v1/groups）
                                                 ▼
                                           UI-006-G（作成したグループの管理画面へ遷移）

【招待メール経由（ログイン状態を問わない）】
  メール内リンク（/invitations/{token}）
        │
        ▼
  UI-009 招待受諾画面
        │
        ├─ 未ログイン時 ─→ UI-001（ログイン/新規登録。?redirect付き）
        │                        │ 認証完了
        │                        ▼
        │                  UI-009（自動で戻る）
        │
        └─ ログイン済み時 ─→ 「参加する」/「辞退する」
                                   │
                                   ▼
                            UI-002（参加完了後、トップへ進む）
```

## 共通コンポーネント

### ボトムナビゲーションバー

UI-002・UI-007・UI-006 で常時表示される固定フッター。

| タブ | アイコン             | ラベル     | 遷移先 |
| ---- | -------------------- | ---------- | ------ |
| 1    | カレンダーアイコン   | カレンダー | UI-002 |
| 2    | 書類スタックアイコン | 書類一覧   | UI-007 |
| 3    | 歯車アイコン         | 設定       | UI-006 |

- アクティブタブのアイコン・ラベルは強調表示（非アクティブはグレー）
- コンテンツ最下部にボトムナビ分の余白を確保し、コンテンツが隠れないようにする

### ログイン・サインアップ画面

**概要**

| 項目   | 内容                       |
| ------ | -------------------------- |
| 遷移元 | アプリ起動（未ログイン時） |
| 遷移先 | UI-002                     |

**画面構成（ログインタブ）**

画面を上下 2 エリアに分割する。

```
┌─────────────────────────────┐
│                             │
│       [アプリアイコン]        │  ← 角丸の正方形アイコン（中央配置）
│                             │
│        プリント管理           │  ← アプリ名（大）
│   書類をスキャンして、家族と共有 │  ← キャッチコピー（小・薄字）
│                             │
├─────────────────────────────┤  ← ヒーローエリアここまで（画面上部 約40%）
│                             │
│  ┌──────────┬─────────────┐ │
│  │  ログイン  │   新規登録   │ │  ← pill 型タブ（アクティブ側は塗り）
│  └──────────┴─────────────┘ │
│                             │
│  メールアドレス               │  ← ラベル（フィールド上部）
│  ┌──[✉]───────────────────┐ │  ← 左端にメールアイコン

│  └────────────────────────┘ │
│                             │
│  パスワード                   │  ← ラベル
│  ┌──[🔒]──────────── [👁] ┐ │  ← 左:鍵アイコン / 右:表示切替アイコン
│  │  ••••••••               │ │
│  └────────────────────────┘ │
│                             │
│               パスワードをお忘れの方 │  ← 右寄せテキストリンク
│                             │
│  ┌────────────────────────┐ │
│  │   [ログインアイコン] ログイン│ │  ← メインアクションボタン（全幅）
│  └────────────────────────┘ │
│                             │
│  アカウントをお持ちでない方は 新規登録 │  ← 下部テキスト。「新規登録」部分がリンク
│                             │

```

**画面構成（新規登録タブ）【v2.0変更】**

```
┌─────────────────────────────┐
│  （ヒーローエリア・タブ切替は同上）│
│                             │
│  メールアドレス               │
│  ┌──[✉]───────────────────┐ │
│  │  taro@example.com       │ │
│  └────────────────────────┘ │
│                             │
│  お名前                      │  ← 【v2.0追加】メールアドレス直下に追加

│  │  お名前（例：山田 太郎）   │ │  ← プレースホルダー
│  └────────────────────────┘ │
│                             │
│  パスワード                   │
│  ┌──[🔒]──────────── [👁] ┐ │
│  │  ••••••••               │ │

│  └────────────────────────┘ │

│  ┌────────────────────────┐ │

│                             │

└─────────────────────────────┘
```

**コンポーネント詳細**

| コンポーネント         | 表示内容・挙動                                                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| ヒーローエリア         | アプリアイコン・アプリ名「プリント管理」・キャッチコピー「書類をスキャンして、家族と共有」を中央配置                                    |
| タブ切替               | 「ログイン」「新規登録」の pill 型セグメント。タップでフォームを切替（同一画面内）                                                      |
| メールアドレス入力     | 左端にメールアイコン。`type="email"`・必須                                                                                              |
| お名前入力             | **【v2.0追加】** 新規登録タブのみ表示。左端に人物アイコン。`type="text"`・必須。`display_name` として POST /v1/auth/signup に送信される |
| パスワード入力         | 左端に鍵アイコン。右端にパスワード表示切替アイコン（目のアイコン）。`type="password"`                                                   |
| パスワード（確認）     | 新規登録タブのみ表示。パスワードと一致することを検証                                                                                    |
| パスワードをお忘れの方 | ログインタブのみ表示。Firebase `sendPasswordResetEmail` で処理                                                                          |
| ログインボタン         | ログインアイコン付き全幅ボタン。Firebase Auth でサインイン後 UI-002 へ遷移                                                              |
| 新規登録ボタン         | 全幅ボタン。Firebase Auth でアカウント作成後、POST /v1/auth/signup を呼び UI-002 へ遷移                                                 |

**新規登録完了後の処理【v2.0更新】**

```
Firebase Auth でアカウント作成
  → IDトークン取得
  → POST /v1/auth/signup { display_name: "山田 太郎" }
      （BE 側で個人グループを自動生成）
  → UI-002 へ遷移
```

**バリデーション**

| フィールド         | ルール                                   |
| ------------------ | ---------------------------------------- |
| メールアドレス     | メール形式・必須                         |
| お名前             | 新規登録時のみ。必須                     |
| パスワード         | 必須。新規登録時は6文字以上              |
| パスワード（確認） | 新規登録時のみ。パスワードと一致すること |

**ヘッダー【v2.0変更】**

**カレンダーエリア**

| 要素                 | 挙動・表示                                 |
| -------------------- | ------------------------------------------ |

| 書類あり日           | 日付の直下に小さいドットを表示             |
| 済スタンプ済のみの日 | ドットを小さく・目立たない表示にする       |

**書類リストエリア**

カレンダー下部にスクロール表示。「{年月}の書類」というセクション見出しを付ける。

| 要素             | 表示内容・挙動                                                 |
| ---------------- | -------------------------------------------------------------- |
| カテゴリアイコン | カード左端。丸背景の中にカテゴリアイコン                       |
| タイトル         | 書類タイトル。長い場合は「...」で省略                          |
| サブテキスト     | 「登録者名・期限日(曜日)」（例：花子・6/12(金)）。薄字・小文字 |
| 残日バッジ       | 右端。「あと N 日」テキスト                                    |
| 済スタンプ       | カード全体をグレー化 ＋ 右端に「✅ 済」テキスト                |
| タップ           | UI-005（書類詳細）へ遷移                                       |

**FAB（Floating Action Button）**

| 要素   | 内容                           |
| ------ | ------------------------------ |
| 位置   | 画面右下固定（ボトムナビの上） |
| 外観   | 円形ボタン。📷 カメラアイコン  |
| タップ | UI-003 へ遷移                  |

**ベルマーク通知ドロワー（タップ時）**

| 要素             | 表示内容・挙動                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| 表示形式         | ドロワーでリスト表示                                                                              |
| 各通知行         | 「{登録者名}が書類を登録しました」＋書類タイトル＋経過時間（例：2分前、1時間前、昨日）            |
| ソート           | `created_at` 降順（新着が上）                                                                     |
| 既読制御         | 通知行を個別タップ → `PATCH /v1/notifications/:id/read`。**自分が登録した書類の通知は表示しない** |
| 未読・既読の区別 | 未読は視覚的に区別（背景・ドット等）                                                              |

**API 連携**

| API                                   | 用途                       |
| ------------------------------------- | -------------------------- |
| `GET /v1/groups/{group_id}/documents` | 書類一覧取得               |
| `GET /v1/notifications`               | 通知一覧・未読件数バッジ用 |
| `PATCH /v1/notifications/:id/read`    | 個別既読更新               |

## UI-003

### 撮影・アップロード画面

**概要**

| 項目   | 内容                 |
| ------ | -------------------- |
| 遷移元 | UI-002（FAB タップ） |
| 遷移先 | UI-004（解析後）     |

**画面構成**

```
┌─────────────────────────────┐
│ [←]  書類をスキャン  [⚡] [⊞]│  ← 左:戻る / 右:フラッシュ・グリッドON/OFF
├─────────────────────────────┤
│                             │
│  ┌─────────────────────────┐│
│  │┌─               ─┐     ││  ← 四隅に白いコーナーマーカー（L字）
│  ││                  │     ││
│  ││    [📄]           │     ││  ← カメラプレビュー領域（全面黒背景）
│  ││  書類を枠内に       │     ││  ← ガイドテキスト（中央）
│  ││  合わせてください   │     ││
│  ││         ─────────│     ││  ← スキャンライン（横線・上下アニメーション）
│  │└─               ─┘     ││
│  └─────────────────────────┘│
│                             │
│  ┌──────┐ ┌───────┐ ┌────┐  │
│  │ [🖼] │ │  [◎]  │ │[📤]│  │  ← 左:ライブラリ / 中央:シャッター / 右:アップロード
│  └──────┘ └───────┘ └────┘  │
│                             │
│  右下のボタンでライブラリから選択できます │  ← 補足テキスト（小・薄字・中央）
└─────────────────────────────┘
```

**コンポーネント詳細**

| コンポーネント        | 表示内容・挙動                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| ナビバー              | タイトル「書類をスキャン」。左端：戻るボタン。右端：フラッシュ ON/OFF ボタン（⚡）・グリッド表示 ON/OFF ボタン（⊞） |
| カメラプレビュー      | 画面いっぱいに表示。四隅に白い L 字コーナーマーカー                                                                 |
| ガイドテキスト        | プレビュー中央に「書類を枠内に合わせてください」を表示                                                              |
| スキャンライン        | 横線が上下にアニメーションで動く（スキャン演出）                                                                    |
| 🖼 ライブラリボタン   | 左端の角丸ボタン。`input[type=file accept="image/*"]` でギャラリーから選択                                          |
| ◎ シャッターボタン    | 中央の大きい円形ボタン（白枠・内側塗り）。ネイティブカメラで撮影                                                    |
| 📤 アップロードボタン | 右端の角丸ボタン。選択した画像を送信                                                                                |
| 補足テキスト          | ボタン列の下に「右下のボタンでライブラリから選択できます」                                                          |

**状態遷移**


## 実装メモ（FE 向け）

| 項目                 | 内容                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| 認証ヘッダー         | 全 API リクエストに `Authorization: Bearer <Firebase IDトークン>` を付与           |
| トークンリフレッシュ | Firebase SDK の `onIdTokenChanged` で自動リフレッシュ                              |
| 環境変数             | Firebase Config・API ベース URL は `.env.local` に格納。コードにハードコードしない |
| レスポンシブ         | スマホ縦（375px〜）基準。`sm:` ブレークポイント以上はデスクトップ用余白を追加      |
| ボトムナビ余白       | コンテンツ最下部に `pb-24` を確保してコンテンツがボトムナビに隠れないよう対処      |
| FAB 位置             | `fixed bottom-24 right-4 z-50` でボトムナビの上に固定                              |
