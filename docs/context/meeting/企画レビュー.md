## 確定 ISSUE

### 書類管理アプリ

#### 誰の課題？

- 書類管理が追いつかない共働き家庭（子どもの学校プリントや保険・医療書類が家族分あって倍増するパパ・ママ）
- 一人暮らしの社会人（請求書、契約書、役所の書類を「とりあえず置く」ことで溜めてしまう人）

#### 何に困っている？

書類が届いた瞬間に内容を把握できても、その後どこにいったか分からなくなったり、提出期限を見落としたりする。

根本原因は、書類の「意味の解釈（これは何か？いつまでか？誰のものか？どこに保存するか？）」を人間が毎回行う必要があり、その判断コストが高いために処理を後回しにしてしまうことにある。

#### 本来はどうあるべき？

書類が来たら自動的に期限や種類が判定され、自動的にカレンダーに登録されて家族全員がリアルタイムに期限を把握できている状態。重要書類がすぐに見つかり、期限前には自動で通知が届くべきである。

#### 既存のソリューションは？

| ツール           | カバー範囲     |
| ---------------- | -------------- |
| CamScannerなど   | 撮影・保存まで |
| Googleフォト     | 撮影・保存まで |
| 付箋・手書きメモ | 撮影・保存まで |

> ※これらはすべて「保存まで」しかカバーしておらず、「意味の解釈・管理・共有」のステップはすべてユーザーの自己責任（人間任せ）のままであるため、根本解決になっていない。

#### その課題が解決されたらいくら払う？

- 個人プラン：月額 300円〜500円 程度
- 家族プラン：月額 800円 程度
