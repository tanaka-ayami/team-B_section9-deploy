## 企画案だし会　6/8（月）

**【課題設定の軸】**
「だれの」「どんな課題を」「どんなテクノロジーを使って」解決するか

---

### ① AIコーデ提案アプリ

| 項目         | 内容                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| だれの       | 配色に困っている人                                                                                                               |
| 課題         | 色の組み合わせで悩む。毎朝コーデを考える時間が取れない。シーンに合った服装か自信が持てない。服だけでなくデザイン時にも課題がある |
| テクノロジー | 服・色の登録クローゼット、AIコーデ提案                                                                                           |

---

### ② 子育て共有アプリ

| 項目         | 内容                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| だれの       | 子育て世代                                                                                              |
| 課題         | 育児情報の格差がある。「どこに行けばいい？」をパートナーに毎回聞く — 情報の非対称が関係のストレスになる |
| テクノロジー | タスク管理・共有機能、パパ・ママ別の体験談、条件入力→コース自動生成                                     |

---

### ③ 子どものスマホ管理アプリ

| 項目         | 内容                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| だれの       | 子どもにスマホを持たせている親                                             |
| 課題         | 気づいたら何時間も使っている。スマホを取り上げると子どもとの関係が悪化する |
| テクノロジー | 使用時間の可視化、ルール達成でポイント獲得                                 |

---

### ④ AI自己成長サポートアプリ

| 項目         | 内容                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| だれの       | 現状に漠然と不満がある人、自己肯定感が低い人、ストレスを抱えている人                             |
| 課題         | 自己肯定感・資産形成・キャリアの悩み。キャリア相談できる相手がいない。頑張りや成長を実感できない |
| テクノロジー | AI対話型の自己分析、ロードマップ自動生成、AIチャット、日記機能、AIによる振り返り支援             |

---
