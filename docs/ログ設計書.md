## 1. ログの目的

| 目的 | 具体的なユースケース |
|------|-------------------|
| **障害調査** | 本番でAPIがエラーを返した際に、どのエンドポイントで・どのユーザーの・どのリクエストが原因かを特定する |
| **利用状況の可視化** | 月間スキャン枚数の集計・AI解析成功率・グループ招待の承諾率などをログから把握する |
| **監査・コンプライアンス** | 誰がどの書類を登録・削除したかの記録。グループへの不正アクセス試行の検出 |
| **AI解析の品質監視** | OpenAI APIの失敗率・レスポンスタイム推移を可視化し、プロンプト改善の判断材料とする |
| **Celeryタスクの追跡** | メールリマインドのスケジュール・送信成否・リトライ状況を可視化する |

## 2. ログレベル定義

| レベル | 用途 | 本アプリでの具体例 |
|--------|------|-----------------|
| FATAL | サービス継続不可となる重大障害 | DBへの接続が完全に失われた / Firebaseの初期化に失敗した |
| ERROR | 機能単位の失敗 | OpenAI APIが3回リトライ後も失敗 / SendGridメール送信失敗 / Alembicマイグレーション失敗 |
| WARN | 想定外だが継続可能な状態 | IDトークンの期限切れ（401）が短時間に多発 / Cloudinaryへのアップロードが遅延 / スキャン上限超過（422）が頻発 |
| INFO | 重要なイベント | ユーザーの新規登録・ログイン / 書類の登録・削除 / グループへの招待承諾 / メールリマインド送信成功 / Stripe決済完了 |
| DEBUG | 開発・調査時のみ | SQLクエリの内容 / Firebase IDトークンのデコード結果 / Celeryタスクの引数 |

> **本番環境では `INFO` 以上のみ出力する**（`LOG_LEVEL` 環境変数で制御）。
> 開発環境では `DEBUG` まで出力する（`.env` の `LOG_LEVEL=DEBUG`）。

## 3. ログフォーマット

### 基本方針

- **構造化ログ（JSON形式）** を基本とする。テキストログは検索・集計が難しいため採用しない
- FastAPIのミドルウェアで各リクエストに **`traceId`（UUID）** を付与し、1リクエストの全ログを横断検索できるようにする
- **個人情報・機微情報はマスクして出力する**（詳細は下記）

### 共通フィールド

```json
{
  "timestamp": "2026-06-30T10:00:00.000Z",
  "level": "INFO",
  "service": "backend",
  "traceId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "userId": "aee3e655-d871-47e5-81c2-b9bc87a73c0d",
  "message": "書類が登録されました",
  "extra": {
    "documentId": "7559053a-b525-422b-a7f6-7e619630d632",
    "groupId": "a3377dc2-4f3d-4ffc-8a64-25b21f612463",
    "endpoint": "POST /v1/documents",
    "statusCode": 201,
    "durationMs": 143
  }
}
```

### マスク対象の個人情報・機微情報

| フィールド | 対応方針 |
|-----------|---------|
| `email` | ログには出力しない。`userId`（UUID）での識別に留める |
| `display_name` | ログには出力しない |
| Firebase IDトークン（JWT） | ログには出力しない。`userId`（`firebase_uid`またはDB上のUUID）に変換して出力 |
| Stripe決済情報 | カード番号・CVV等は一切出力しない。`stripeEventId`のみ記録 |
| SendGrid APIキー | ログには出力しない |
| Cloudinaryの署名付きURL | URLそのものは出力しない。`cloudinaryPublicId`のみ記録 |
| `invitee_email`（招待先メール） | ログには出力しない |

## 4. 出力先・収集

### 出力先

| サービス | 出力先 | 収集方法 |
|---------|--------|---------|
| FastAPI（バックエンド） | 標準出力（stdout） | Docker / Render のログストリームで収集 |
| Celery Worker | 標準出力（stdout） | 同上 |
| Celery Beat（スケジューラー） | 標準出力（stdout） | 同上 |
| Next.js（フロントエンド） | Vercelのビルド・ランタイムログ | Vercelダッシュボード |

### ログ収集基盤（Week2時点の方針）

- **開発環境**：`docker compose logs -f [service名]` でリアルタイム確認。永続化不要
- **本番環境**：Renderのビルトインログ機能で確認（Week2デプロイ時点）。将来的に余裕があれば **Datadog** または **CloudWatch** への転送を検討

### ログの種別

| 種別 | 内容 | 出力レベル |
|------|------|----------|
| アクセスログ | 全HTTPリクエスト（メソッド・パス・ステータスコード・応答時間・traceId） | INFO |
| アプリケーションログ | ビジネスロジックの重要イベント（書類登録・グループ招待・メール送信等） | INFO / WARN / ERROR |
| 認証ログ | ログイン・IDトークン検証・401/403エラー | INFO / WARN |
| Celeryタスクログ | タスク開始・完了・失敗・リトライ | INFO / ERROR |
| デバッグログ | SQLクエリ・外部API通信の詳細 | DEBUG（開発環境のみ） |

## 5. 保存期間

| 種別 | 保存期間 | 保存先 | 備考 |
|------|---------|--------|------|
| アクセスログ | 90日 | Renderログストリーム / 将来的にDatadog等 | 障害調査に必要な最低限の期間 |
| アプリケーションログ（INFO以上） | 90日 | 同上 | 利用状況可視化・障害調査 |
| 監査ログ（書類の登録・削除・グループ操作） | 1年以上 | 同上（長期保存が必要な場合はS3等へエクスポート） | コンプライアンス対応 |
| デバッグログ | 7日 | ローカル / 開発環境のみ | 本番には出力しない |
| Celeryタスクログ | 90日 | 同上 | リマインド送信の追跡 |

## 6. 監視・アラート

### アラートルール

| 条件 | レベル | 通知先 | 備考 |
|------|--------|--------|------|
| ERRORログが5分間に10件以上 | 緊急 | チームSlack / メール | バックエンドの大規模障害の可能性 |
| FATALログが1件でも発生 | 緊急 | チームSlack / メール | DBダウン等、即時対応が必要 |
| OpenAI解析エラー率が30%超（5分間） | 警告 | Slack | APIキー枯渇・レート制限の可能性 |
| SendGridメール送信エラーが連続5件 | 警告 | Slack | リマインドメールが届いていない可能性 |
| Celeryタスクが30分以上滞留 | 警告 | Slack | Workerのクラッシュ・Redisの問題の可能性 |
| `/v1/documents/scan` の平均応答時間が10秒超 | 警告 | Slack | OpenAI APIの遅延・タイムアウトの可能性 |

### 異常検知

| 検知対象 | 閾値 | 対応方針 |
|---------|------|---------|
| 全APIのエラー率（5xx） | 5分間で5%超 | 即時調査。デプロイ直後であればロールバックを検討 |
| 認証エラー（401）の急増 | 5分間に50件超 | Firebaseの障害またはトークン失効の一斉発生を疑う |
| DBクエリのレイテンシ | 平均500ms超 | インデックスの欠落・N+1クエリの可能性。スローログを確認 |
| Celeryタスクのリトライ率 | 10%超 | SendGrid / OpenAI の外部障害を確認 |

### Week2時点の暫定対応

- 本番デプロイ（#11・#28）完了前の現時点では、Renderのビルトインログを手動で確認する
- アラート自動通知（Slack連携等）はWeek3の発表準備期間以降、余裕があれば実装を検討する
- 緊急時はRenderのダッシュボードからリアルタイムログを確認し、チームのSlackで共有する
